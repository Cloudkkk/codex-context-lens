这是插件的一次初始化操作，不需要用户先发测试消息或信任 SessionStart hook。

1. 本技能文件所在目录上两级是插件根目录。用 `/bin/sh "<插件根目录>/scripts/run-python.sh" initialize` 执行初始化；保留运行环境中的 `CODEX_THREAD_ID`，不得使用 latest 或其他聊天替代当前聊天。
2. 初始化需要读取桌面进程、连接本机调试端口，并为明确授权的初始化安排正常退出。**首次执行必须通过 `exec_command` 的 `sandbox_permissions: "require_escalated"` 申请沙箱外权限**，`justification` 写明「初始化 Context Lens，启动监控并在任务结束后正常退出、重开桌面端」。不能先在受限沙箱运行再把进程检查失败解释为桌面未启动。若平台拒绝执行权限，说明实际拒绝原因并停止，不绕过审批。
3. 命令会启动监控，并安排在本轮 `task_complete` 写入后正常退出、带本地调试参数重开桌面端。初始化操作本身包含重启授权，无需再请求用户手动 ⌘Q，也不要执行其他关闭应用的命令。
4. `ready` 表示端口已可用且监控已启动，回复「初始化完成；将鼠标移到已完成回复，再悬停时间左侧的饼图按钮。」不要把此状态当作已验证 hover。
5. `waiting_for_tasks` 表示重启已排队，简短回复「已安排自动重启，当前回复及其他本地任务结束后会执行；无需手动退出。」然后结束本轮，让日志记录完成。不要等待重启完成，否则会阻止重启条件达成。
6. 命令失败时说明实际错误；不要改写 hook 信任、账户设置、应用包，也不要强退应用或猜测已经成功。尤其 `执行权限不足` 表示进程检查被沙箱拦截，不是用户选择了错误入口。

Hook 只负责可选的后续监控恢复，初始化不依赖其信任状态。应用拒绝正常退出、日志状态不明确或等待超过 15 分钟时取消此次重启；不得强退或循环重启。
