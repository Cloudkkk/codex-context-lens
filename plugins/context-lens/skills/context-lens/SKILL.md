---
name: context-lens
description: 自动启用、停止或修复 Codex 消息操作栏中的上下文悬停面板，无需独立启动器。仅处理面板维护，不用于聊天查询 token 明细。
---

插件入口是消息下方操作栏最右侧的 16px SVG 饼图图标与百分比按钮，默认隐藏，回复 hover、键盘聚焦或面板打开时显示；hover 显示分类汇总（暂不支持展开明细），点击固定面板，Esc 关闭。

面板维护命令在本技能目录上两级的 `cli.py`。使用 Python 3.9+；`enable` / `start` 启动自动启用监控，`status` 查看进程和连接状态，`stop` 撤掉按钮和面板，并取消尚未执行的重开。

插件的 `SessionStart` hook 自动启动监控；用户需要在桌面端「设置 → Hooks」或终端 CLI 的 `/hooks` 中审核并信任 hook。首次挂载要求桌面应用带本地调试参数启动：监控发现端口缺失且主应用正在运行时进入 `waiting_for_app_exit`；用户等任务结束后完全退出一次，监控自动带参数重开，不需要任何独立启动器。已有端口时直接挂载；已连接应用正常退出后不会被重开。不得强退应用或修改应用包。CLI-only 会话不会自动打开桌面端。

收到启用或修复请求时运行 `enable`，读取 `status`；`attached` 表示监控已经连接窗口，`waiting_for_app_exit` 表示等待首次退出并自动重开，`restart_failed` 表示该版本未开放端口或启动失败。不要声称安装即信任 hook、会话开始即插件加载，或未经实际交互验证就声称 hover 已显示。用户关闭插件开关时，监控也会停止。

`status.windows` 包含插件内部的会话和挂载计数。`buttons > 0` 表示按钮已挂载；`diagnostics.reason` 的 `no_turn_match` 表示文案或 ID 不能唯一匹配，`no_action_rows` 表示消息操作栏结构不兼容。不要把 `attached` 当作 hover 成功。0.2.2 的实际按钮和面板已由用户确认正常；后续故障仍需核对当前计数。

保持只读：日志默认来自 `~/.codex/sessions`，不修改日志、应用包或账户设置。面板按会话 ID 和轮次 ID 匹配；不能确定对应轮次时不挂载。输入总量来自用量事件，分类仅是可见文本估算；不要把差额解释为精确工具占用。无需添加 MCP 聊天查询工具。
